# Introduction to toupac

``` r

library(toupac)
```

`toupac` provides convenience functions for some common tasks. To
install this package from GitHub, use

``` r

# install.packages("remotes")
# install.packages("devtools")
devtools::install_github("voob/toypackage")
```

functions

- `strsplit1`
